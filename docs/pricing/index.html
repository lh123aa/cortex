Three commands

三步，它就开始记得了

1

指向你的目录，建一次索引

cortex index ~/notes ~/Documents —— 切块、去重、建索引。默认纯 BM25，不需要显卡，不需要向量库，不需要 Docker。

2

启动，它自己接进你的编辑器

cortex start —— 起 MCP 服务，并把配置写进 Claude Code / Cursor / OpenCode / Trae。带备份，不覆盖你已有的 MCP server。

3

提问，它自己去查，还告诉你出处

问「上次那个方案怎么定的」，它调检索工具找到那段笔记原文，而不是编一段看起来合理的答案。

Objections

你在犹豫的四件事

开源免费，为什么还要给你钱？

核心是 Apache-2.0，确实免费，你自己装也能用。Pro 卖的不是代码，是「容量不用管」和「不用自己折腾重排、自动索引」这两段时间。你按小时算就明白：省下的工时远超过 ¥199。

要不要显卡、要不要装数据库？

都不要。默认纯 BM25 关键词检索，单文件跑；向量检索是可选项，不装也能用。

License 会不会偷偷联网校验？

不会。Ed25519 签名，公钥内置在二进制里，本地校验。不联网、不上报、不采集使用数据 —— 断网状态下照样可用。

哪天你不做了，我手上的还能用吗？

能。核心代码开源在 GitHub，License 是离线的、永久有效的，不依赖任何服务器。最坏情况下你手上的版本可以一直跑下去。
