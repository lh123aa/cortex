# MCP Protocol Overview

MCP (Model Context Protocol) is a standard for AI Agent communication.
It defines how agents interact with tools and resources.

## Key Concepts

- Tools: Functions that agents can call
- Resources: Data sources that agents can read
- Prompts: Templates for agent interactions

## MCP Transport

MCP supports two transport modes:
1. stdio - for local agent integration
2. SSE - for remote agent integration
